## The Twisted Problem

**Given: K drops allowed**  
**Find: Maximum floors we can check**

## Let's Build From Scratch

Say K = 3 (I have 3 drops total).

### My Strategy:

**Drop 1**: Go to floor ?
- If it breaks: I have 2 drops left
- With 2 drops left, I can check how many floors below? 
  - Drop at floor 1, then floor 2 → I can check 2 floors
- So I should go to floor **3** on my first drop

**Drop 2** (if egg 1 survived): Go to floor 3 + ?
- If it breaks: I have 1 drop left
- With 1 drop left, I can check 1 floor
- So I jump **2** floors → floor 5

**Drop 3** (if egg 1 still survived): Go to floor 5 + ?
- This is my last drop, I can only check 1 more floor
- So I jump **1** floor → floor 6

**With K=3 drops → I can check 3+2+1 = 6 floors**

## General Pattern

**With K drops allowed:**
- 1st drop: go to floor K
- 2nd drop: jump (K-1) floors
- 3rd drop: jump (K-2) floors
- ...
- Kth drop: jump 1 floor

**Maximum floors = K + (K-1) + (K-2) + ... + 1 = K×(K+1)/2**

## Examples

- K=4: 4+3+2+1 = 10 floors
- K=5: 5+4+3+2+1 = 15 floors
- K=10: 10+9+...+1 = 55 floors
- K=14: 14+13+...+1 = 105 floors

Now we flip it: **If I have 100 floors, what's minimum K?**

Find smallest K where K×(K+1)/2 ≥ 100 → **K = 14**
