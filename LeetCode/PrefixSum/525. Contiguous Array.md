      class Solution {
      public:
          int findMaxLength(vector<int>& nums) {
              int n = nums.size();
              
              for (auto& val : nums) {
                  if (val == 0) val = -1;
              }
              
              
              unordered_map<int, int> first_occ_pIdx;
              int prefixSum = 0;
      
              first_occ_pIdx[0] = -1; // require for subarr starting at 0 idx [   ]  
      
              int ans = 0;
              for (int i = 0; i < n; i++) {
                  prefixSum += nums[i];
      
                  if (first_occ_pIdx.count(prefixSum)) {
                      ans = max(ans, i - (first_occ_pIdx[prefixSum]));
                  } else {
                      first_occ_pIdx[prefixSum] = i;
                  }
              }
              return ans;
          }
      };





Two core facts unlocked for prefix-sum subarray problems:

1. **Prefix sum + equation:**
   Any subarray sum condition (e.g., divisible by `k`) reduces to an **equivalence condition**:

   ```
   prefix[r] - prefix[l-1] % k == 0  ⇨  prefix[r] % k == prefix[l-1] % k
   ```

2. **Hash table / array role:**
   Store **first occurrence or count** of each prefix (or remainder).
   Lookup lets you instantly check if a previous prefix satisfies the condition, giving **O(1) query per step**.
